## โปรเจคนี้เป็นส่วนหนึ่งของวิชาวิศวะกรรมซอฟต์แวร์ 
# รหัสวิชา BSCCS304 (ภาคเรียนที่ 1/69) by Phuri

# ฟีเจอร์การทำงาน (Features)
1. เครื่องคิดเลขนี้ทำงานผ่าน COmmandline (Terminal)
2. มีฟังก์ชันทางคณิตศาสตร์เบื้องต้นและขั้นสูงดังนี้ :
-  + การบวก (Addition)
-  - การลบ (Subtraction)
-  * การคูณ (Multiplication)
-  / การหาร (Division)
